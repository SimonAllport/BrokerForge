# Phase 1 core implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The Orders mock API supports list (with declared filters and paging), retrieve, create, update and delete through a Dataverse virtual table. An undeclared filter throws `UnsupportedQueryException`, and an unmapped 500 throws `SourceException` with the correlation ID.

**Architecture:** The plug-in turns each of the five messages into a canonical request and posts it to the host. The host checks the caller, resolves the object map and descriptor, plans the query against the descriptor's declarations, and renders the source request. It then attaches credentials, executes the request through the REST adapter and maps the response back. Phase 1 config (service instances, object maps) lives in host configuration and descriptors are files baked into the image. The Dataverse config tables arrive with the generator in phase 2.

**Tech stack:**
- Contracts: `netstandard2.0`
- Plug-in: `net462`, `Microsoft.CrmSdk.CoreAssemblies` 9.0.2.60
- Host: .NET 8 minimal APIs
- Descriptors: YamlDotNet (representation model, not the POCO deserialiser) and JsonPath.Net (RFC 9535)
- Keys property tests: FsCheck.Xunit
- Tests: xUnit
- Mock API: Node 26 with built-in `node:http`, no npm dependencies
- Infra: Bicep
- Secrets: Azure.Identity and Azure.Security.KeyVault.Secrets

**Spec:** `docs/hld.md` (sections 4–11, 16), `docs/descriptor-spec.md`, `docs/findings/phase0.md`, `CLAUDE.md` (phase 1 criteria, testing rules).

Work on branch `phase1-core`, created from `phase0-spike`.

## Global constraints

- Fail loudly. Never return partial, approximate or client-side-filtered results. Every unsupported construct is a typed exception naming the cause.
- No secrets in Dataverse rows, descriptors, logs, traces, test fixtures or exception messages. No test uses a real secret.
- Thin plug-in. It translates messages into the canonical request and back. No source logic, no descriptor logic, no credentials.
- The plug-in compiles Contracts source in through linked `Compile` items (HLD D-08). Contracts DTOs use `[DataContract]`/`[DataMember(Name = camelCase)]`, and every value crossing the wire is a string or a string list.
- The host maps the token's `azp` to exactly one allowed environment ID and rejects a request whose `environmentId` differs (HLD D-09).
- Host timeout is 90 seconds per canonical request, covering retries and paging calls together (HLD 11, NFR-02).
- Every request and log line carries `correlationId`.
- Exceptions live in Contracts and end in `Exception`: `UnsupportedQueryException`, `ConnectionRequiredException`, `SourceException`, `SourceTimeoutException`, `MappingException`, `BrokerUnavailableException`.
- Error bodies quoted from a source are redacted and at most 500 characters (descriptor spec 8).
- Host `minReplicas >= 1` wherever users call it (phase 0 cold start was 23.5 s).
- Ask before changing a contract in `BrokerForge.Contracts` or the descriptor schema, and update the docs in the same change. Task 0 is that ask for this phase.

## Review focus

1. **Dataverse adds sorts and filters the user did not choose.** Default views and Web API queries can add an order or a condition on a column the descriptor doesn't declare. The error must name the column and operator so an admin can fix the view or the descriptor. Test in Task 6: `Plan_UndeclaredSort_MessageNamesColumn`.
2. **Large page requests.** The Web API asks for 5000 rows when no `maxpagesize` is set, while the source caps at 100. Under G9 the host returns at most `max × maxCallsPerPage` rows plus a next token, and does not throw. Test in Task 11: `Page_RequestLargerThanFillBudget_ReturnsFullCallsWithNextToken`.
3. **Forged or stale page tokens.** A token from another operation, an older descriptor version or with corrupt bytes must be refused, not treated as page 1. Test in Task 11: `Token_FromOtherOperation_ThrowsUnsupportedQuery`.
4. **Link paging as a request-forgery route.** A `link` token carries a URL. The host must only follow URLs under the service instance's base URL. Test in Task 11: `LinkToken_OutsideBaseUrl_ThrowsUnsupportedQuery`.
5. **Optional fields missing from source rows.** JSON APIs often omit absent fields. Under G8, a missing path is a `MappingException` unless the map entry says `optional: true`, and JSON `null` maps to null. Test in Task 8: `Map_MissingPathNotOptional_ThrowsMappingNamingPath`.

Reversible layout (fixed so the format can't drift):

| Kind | byte 0 | Then | Remaining bytes |
| --- | --- | --- | --- |
| Int32 | `0x01` | bytes 1–8: the value as little-endian int64 | zero |
| Int64 | `0x02` | bytes 1–8: the value as little-endian int64 | zero |
| String | `0x03` | byte 1: UTF-8 length (0–14), bytes 2..: the UTF-8 bytes | zero |

The GUID is `new Guid(bytes)`. Decode rejects any of these with `InvalidKeyException`: a wrong type byte for the configured kind, non-zero padding, a length over 14, or invalid UTF-8.
